A simple three-level hierarchy

Every Links page uses the same three-level structure: 

lk-container
└── lk-section
    └── lk-block-*
  • lk-container is the single page frame.
  • lk-section groups related content.
  • lk-block-* is the actual UI component.

Keep the hierarchy flat: place sections inside the container and blocks inside sections. Avoid nesting sections inside sections or independent blocks inside blocks.

Section with a surface

Sections have their material-aware semantic surface by default. has-background can state that intent explicitly or restore the surface after composing utilities.

Transparent section

has-no-background removes the section fill, border, shadow, and its own backdrop filter while preserving its place in the hierarchy.

Component lk-block-text

Long-form content

Text blocks support headings, paragraphs, inline links, and native lists without pretending to be a card.

Inline prose can use bold, italic, inline code, deleted text, and a well-kept secret.

Good uses

  • A short introduction
  • Project notes or contact details
  • Small pieces of documentation like this page

Text with a surface

Text blocks are transparent by default. Add has-background when the content needs stronger separation from the wallpaper.

Component lk-block-figure

Put a semantic figure inside an anchor when the entire image should be clickable. The first example keeps the default surface, border, and padding. A figcaption is useful but optional when the image already has an appropriate alt description.

Materials and wallpaper

Three material profiles

  • data-material="solid"
  • data-material="mica"
  • data-material="acrylic"

Add data-wallpaper-effect="material" to process the wallpaper with the selected material profile. A native picture can provide separate light and dark images.

Add hidden to lk-wallpaper-source, or omit the picture entirely, to disable the wallpaper.

The entire color system uses Catppuccin Latte and Mocha, following prefers-color-scheme without a manual theme state.

Utilities

State and utility classes remain independent from components, so they can be combined where their meaning fits.

  • has-background and has-no-background control a semantic surface.
  • has-no-padding removes internal spacing.
  • is-rounded circularly crops an image.
  • is-spoiler hides text until hover or keyboard focus.
  • is-left-aligned, is-center-aligned, is-right-aligned, and is-justify-aligned control text alignment.
  • Catppuccin utilities include red, peach, yellow, green, blue, and mauve.

is-rainbow provides a proud, hard-edged rainbow style.
